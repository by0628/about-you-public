# 每日一句 × 情緒色卡

一個安靜的數字角落。每天打開，有一句話慢慢打出來——
像有人在你耳邊輕輕念一句話那種感覺。
然後選個顏色，就當今天情緒有個落腳的地方。

80 句。原創 5 句，文學摘錄 65 句，動漫台詞 10 句。
佩索阿、張愛玲、博爾赫斯、加繆、里爾克、木心、魯迅、太宰治、
杜拉斯、薩特、尼采、莊子、辛波斯卡、泰戈爾、叔本華、
三毛、王小波、汪曾祺……還有魯魯修和柯南。
從「我是一個迷路的人，但我不急著找到方向」到「真相只有一個」，
跨度大概就是這樣——認真，但不總是嚴肅。

打字機效果。逐字出現，標點處自然停頓，長句自動折行。
不是裝飾，是節奏——讓你讀完上一句，才接得住下一句。

30 種情緒，6 組色調：冷調、暖調、暗調、亮調、自然、深淵。
選完之後會生成一張專屬卡片，可以存成 PNG。
同時還有一張邀請卡，會跟著你選的顏色一起變色——
不是換個標籤那種變，是整張卡片的氛圍跟著情緒走。

背後在幹的事：
- 首次打開用本地庫（不跳空白），API 在後台悄悄預加載
- 換一句有 50% 機率從 API 拿新句子，其餘走本地隨機
- 已讀計數，記著你一共讀了多少句
- 情緒周報：連續記錄 7 天以上，會告訴你這週最常停留在哪種顏色
- 天氣模糊中文（「小雨 18°C」這種），時間實時同步
- 空格換句，Esc 關閉彈窗

所有數據只存在你自己的瀏覽器裡。
不上傳、不追蹤、沒有 Cookie Banner、沒有 Telemetry。
關掉就沒了，換設備就沒了——這是設計，不是 bug。

技術上沒什麼好炫耀的：純 HTML + CSS + JS，零構建，
GitHub Pages 託管，`.nojekyll` 保證路由正常。
`html2canvas` 按需從 CDN 載入，用到的時候才拉。
`localStorage` 三個 key 各管各的：已讀計數、情緒記錄、API 狀態。
