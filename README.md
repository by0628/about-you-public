## ✦ 關於這份問卷

這不是一份性格測試，也不是一份調查表。  
它更像一封**寫給朋友的慢信**——邀請對方停下來，用一種溫柔的方式，重新看一眼自己。

- 51 題，分為 9 個章節
- 支持多選 / 單選 / 滑動輸入 / 自由填寫
- 所有數據**僅存於填寫者設備**
- 無登入、無追蹤、無後端

---

## ✦ 設計理念

### 視覺
- **字體**：Noto Serif CJK SC（襯線標題）+ Noto Sans CJK SC（正文）
- **配色**：Quiet Luxury 色板（燕麥 / 黛藍 / 赭石 / 霧霾粉 / 鼠尾草綠）
- **質感**：極細線條、微陰影、留白優先、無炫技動畫
- **印刷**：專為 A4 打印優化，自動將交互控件轉為純文本

### 交互
- Chip 多選 / MBTI 單選 / 顏色多選 / 天氣單選
- 社交電量滑塊（1–10）
- 結果一鍵複製 / 下載 TXT / 瀏覽器打印（PDF）

### 技術
- 純 HTML / CSS / JavaScript
- 零依賴、零構建、零後端
- 單文件即可運行

---

## ✦ 使用方式（給填寫者）

1. 打開鏈接
2. 慢慢填寫，可跳過任何題目
3. 點擊「完成問卷」
4. 選擇：
   - 📋 **複製全部答案**：貼到微信發給我
   - 📄 **下載 .txt 文件**：保存後發回
   - 🖨️ **列印 / 存 PDF**：桌面端最穩

> iOS Safari 用戶建議使用「複製答案」或「下載 .txt」，打印功能在移動端可能不穩定。
